# ThinkFlow

ThinkFlow 是一个面向论文阅读、产品调研、课程学习和团队汇报的 AI 知识工作台。它把来源导入、基于来源的对话、可沉淀的知识资产和多形态产出放在同一个笔记本里，让一次资料处理可以持续演化为摘要、梳理文档、产出指导、报告、导图、卡片和测验。

## 核心闭环

ThinkFlow 的工作流不是一次性聊天，而是一个可追踪的知识生产闭环。

1. **来源进入笔记本**：用户可以上传文件、粘贴文本、导入网页，也可以通过搜索或深度研究补充外部资料。来源集中显示在左侧栏，并可被选择参与对话和产出。
2. **对话围绕来源展开**：中间区域用于基于来源提问。回答旁边提供显式沉淀入口，可以把单条回答、一轮问答或多条消息沉淀为长期资产。
3. **知识资产持续维护**：右侧工作区维护 Summary、梳理文档和产出指导。它们不是聊天副本，而是后续报告、导图、PPT 等产出的增强上下文。
4. **产出锁定来源快照**：产出生成会确认当次使用的来源、梳理文档和产出指导。结果版本不会在当前会话里动态换源，需要新范围时重新生成一版。

![来源与三栏工作区](assets/thinkflow/workspace-sources.png)

## 三栏工作区

进入笔记本后，ThinkFlow 以三栏方式组织工作。

- 左侧栏管理历史对话、当前素材和已生成产出。
- 中间栏承载主对话，是围绕来源持续探索问题的地方。
- 右侧栏承载知识资产和产出工作台，用户可以在这里编辑文档、查看结果、回流产出。

这种布局适合连续工作：来源保持可见，对话保留上下文，右侧知识资产随时可以被选为后续产出的输入。

## 知识沉淀

### Summary

Summary 是多级卡片。它适合保存从对话中提炼出的关键结论，也可以进一步重算为总 Summary。走查中创建了“走查摘要卡”，用于概括 ThinkFlow 的来源、对话、沉淀和产出闭环。

![Summary 卡片](assets/thinkflow/summary-panel.png)

### 梳理文档

梳理文档是后续报告、导图和 PPT 的主输入区。它用于保存经过用户确认的正文内容，而不是临时聊天副本。走查中创建的梳理文档把 ThinkFlow 工作流拆成四步：来源进入笔记本、对话形成可沉淀知识、右侧维护长期资产、产出锁定来源快照。

![梳理文档](assets/thinkflow/document-panel.png)

### 产出指导

产出指导是只读的高权重 brief，用来告诉后续产出应该强调什么、避免什么、采用什么口径。它会参与大纲和正式生成，适合从关键问答里提炼，而不是直接当作普通文档编辑。

![产出指导](assets/thinkflow/guidance-panel.png)

## 适用场景

- **论文阅读**：把论文、实验记录和参考材料统一导入，围绕方法、贡献、实验和局限持续提问，再沉淀为摘要、梳理文档和汇报材料。
- **产品调研**：把网页、竞品资料、访谈纪要和行业报告整合为来源，生成竞品分析、调研报告和路线图讨论材料。
- **课程学习**：把教材或讲义转为问答、卡片和测验，形成可复习的学习资产。
- **团队汇报**：把原始资料加工为报告、导图和 PPT 大纲，并保留来源快照，方便回溯结果依据。
